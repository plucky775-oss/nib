보정 강도가 높을수록 잔떨림과 불규칙한 곡선을 더 정돈합니다. 글자의 모양을 인식해 교정하는 기능은 아닙니다.

자동 변환을 켜면 필기를 멈춘 뒤 새 획을 모아 AI로 읽습니다. 필기를 멈춘 뒤 1.2초 후 처리하며, 수동·자동 합계 최근 1분 최대 6회이고 비용이 발생합니다. 원본은 보존됩니다.

내 필체 다듬기

획의 작은 흔들림을 완화합니다. 글자의 뜻을 인식하거나 악필의 모양·간격을 자동 교정하는 기능은 아닙니다. 원본 보기로 언제든 비교할 수 있습니다.

예쁜 필체로 변환

두 모드 모두 원본 종이에 Pencil로 필기합니다. 예쁜 필체는 직접 변환하거나 자동 변환을 켜 원본을 읽은 뒤 무료 글씨체로 표시합니다. 자동 변환은 멈춘 필기를 모아 처리하며 API 비용이 발생합니다. 결과는 같은 종이의 원본 필기 영역에 선택한 폰트로 표시되며, 원본 획 보기는 같은 위치에서 표시만 바꿉니다. 정확한 원래 자간까지 복원하는 기능은 아닙니다. 키보드 수정은 별도 창에서 합니다. iPad 자체 손글씨 입력과 Nib AI는 서로 다릅니다. AI 인식에는 연결과 이용 코드가 필요하며 오인식할 수 있으니 결과를 확인하세요.

안전하게 보관하기

기기 간 동기화는 없습니다. 브라우저 데이터 삭제나 비공개 모드 종료로 노트가 사라질 수 있으니 백업을 저장해주세요. 백업 불러오기는 기존 노트를 덮어쓰지 않고 새 복사본을 추가합니다.

현재 노트의 원본 필기 이미지를 Google Gemini 3.1 Flash-Lite로 전송합니다. 인식 사용량에 따라 API 비용이 발생할 수 있습니다. 노트 제목이나 다른 노트는 전송하지 않습니다.
